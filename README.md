# PAD · Лабораторная работа №4 — «Курсы НБМ» (мобильное приложение)

Мобильный конвертер валют с экранами аналитики за неделю и месяц.
**React Native + Expo SDK 58, TypeScript.** Вариант Б: перенос конвертера из Лаб 3 (там Go + Fyne)
на мобильную платформу. Логика написана заново на другом языке.

## Экраны

| Экран | Содержимое |
|---|---|
| **Конвертер** | сумма, «Из валюты» / «В валюту», ⇄, кнопка «Конвертировать» (неактивна без суммы), результат, дата курса, источник |
| **Неделя** | график курса выбранной пары за 7 дней, минимум, максимум, среднее, изменение (абс. и %), тенденция ▲ рост / ▼ падение / ■ без изменений |
| **Месяц** | то же за 30 дней |

Пара валют общая для всех экранов: выберите её на «Конвертере». Потяните экран вниз, чтобы обновить.

## Запуск

```bash
npm install
npm start
```

Откройте приложение **Expo Go** на телефоне (App Store / Google Play) и отсканируйте QR-код из терминала.
Телефон и компьютер должны быть в одной сети (или запустите `npx expo start --tunnel`).

Эмулятор: `npm run android` (нужен Android Studio) или `npm run ios` (нужен Xcode).

## Тесты

```bash
npm test
```

| Файл | Что проверяется |
|---|---|
| `__tests__/bnm.test.ts` | разбор XML BNM: nominal, запятая, битые элементы, пустой ответ, HTML, коды HTTP, обрыв сети |
| `__tests__/stats.test.ts` | минимум, максимум, среднее, абс. и % изменение, тенденция, пустой набор, одна точка |
| `__tests__/money.test.ts` | валидация суммы, конвертация в обе стороны, одинаковые валюты, форматирование, даты |
| `__tests__/repository.test.ts` | откат на прошлые дни, кэш после «перезапуска», офлайн без кэша, история 7/30 дней из кэша |

Живая проверка с реальным bnm.md: `LAB4_LIVE=1 npx jest live`. Проверка типов: `npm run typecheck`.

### UI-тесты (Playwright)

```bash
npm run test:e2e
```

Playwright собирает веб-версию приложения (`expo export --platform web`), открывает её в установленном
Google Chrome с эмуляцией телефона Pixel 7 и проходит сценарии. Ответы bnm.md подменяются через
`page.route`, а время зафиксировано на 24.11.2026, поэтому тесты не зависят от сети и даты.

| Файл | Сценарии |
|---|---|
| `e2e/converter.spec.ts` | дата и источник; кнопка неактивна без суммы; EUR→MDL и обмен ⇄; выбор валюты из списка, кросс-курс; одинаковые валюты; 4 вида неверного ввода; нет курса на сегодня; нет сети без кэша; кэш после перезапуска без сети |
| `e2e/analytics.spec.ts` | неделя и месяц: график, минимум, максимум, среднее, изменение, %, «Рост»/«Падение»; одинаковые валюты; пропущенные дни; офлайн из кэша; офлайн без кэша |
| `e2e/screenshots.spec.ts` | скриншоты всех экранов в `test-results/screens/` |

Наглядно, с видимым браузером и паузой 0,5 с между действиями:

```bash
npm run test:e2e:headed
```

Скорость меняется через `SLOWMO` (в миллисекундах): `SLOWMO=1500 npm run test:e2e:headed`.
Интерактивный режим, где можно выбирать тесты и проходить их по шагам: `npm run test:e2e:ui`.

Отчёт с трассировкой упавших тестов: `npm run test:e2e:report`.

> Веб-версия нужна только для тестов. В обычном браузере bnm.md не отдаёт данные из-за CORS;
> на телефоне (Expo Go) этого ограничения нет.

## Данные

- Источник — официальный XML НБМ: `https://www.bnm.md/en/official_exchange_rates?get_xml=1&date=ДД.ММ.ГГГГ`.
- История — запрос на каждый день (до 5 параллельно). Каждый день сохраняется в AsyncStorage
  (`day:ДД.ММ.ГГГГ`) и больше не скачивается; заново запрашивается только сегодняшний день.
- Последний курс (`latest`) хранится локально и переживает перезапуск.

## Офлайн

| Ситуация | Поведение |
|---|---|
| Нет сети, есть кэш | Жёлтое сообщение «Нет соединения… сохранённый курс от ДД.ММ.ГГГГ» + время сохранения; конвертация и графики работают |
| Нет сети, нет кэша | Сообщение, кнопка «Повторить загрузку», ничего не падает |
| Нет курса на сегодня | Берётся последний опубликованный (до 10 дней назад) с сообщением |
| Часть дней истории недоступна | График по доступным дням и сообщение «Нет данных за N из M дней» |

